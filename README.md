# Map-Check
Downloads MCSR practice maps

If you want your map added or  have any issues or suggestions you can dm me on discord. @cylorun

# Usage
- Run the jar file and select instances, to select multiple you can use **ctrl** or **shift**. You only need to select the instance directory, **not saves or .minecraft**.
- Select the maps you want and press **Download**.
- Before downloading, Map-Check checks each selected map's latest stable GitHub release and downloads its map ZIP. The catalog's existing links identify the repository and map asset, rather than pinning the installed version. If a release check fails or the map ZIP is ambiguous, installation stops with an error.
