# Map-Check
Downloads MCSR practice maps

If you want your map added or  have any issues or suggestions you can dm me on discord. @cylorun

# Usage
- Run the jar file and select instances, to select multiple you can use **ctrl** or **shift**. You only need to select the instance directory, **not saves or .minecraft**.
- Select the maps you want and press **Download**.
- Before every download, Map-Check checks each selected map's latest stable GitHub release and downloads its map ZIP. The repository list is bundled in the JAR and contains no pinned release URLs. Old external `maps.json` files are ignored. If a release check fails or the map ZIP is ambiguous, installation stops with an error. The completion dialog lists the installed map folders.
